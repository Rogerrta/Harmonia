#  Harmonia

Aplicação web para organização e consulta da programação das reuniões da **Congregação Noroeste**.

O projeto foi desenvolvido com foco em simplicidade, facilidade de consulta e boa experiência em dispositivos móveis.

## 🌐 Acesso

A versão publicada está disponível através do GitHub Pages:

**Harmonia — Congregação Noroeste**

https://rogerrta.github.io/Harmonia/

---

## 📱 Objetivo

O Harmonia foi criado para facilitar o acesso à programação das reuniões e às designações semanais.

A proposta é permitir que a programação seja consultada rapidamente tanto em computadores quanto em celulares.

Entre as informações disponibilizadas estão:

- Programação da reunião do meio de semana
- Designações semanais
- Reunião do final de semana
- Acesso às semanas do mês
- Identificação rápida da programação atual

---

## ✨ Interface

A interface está sendo desenvolvida seguindo alguns princípios:

- Design simples e limpo
- Navegação intuitiva
- Prioridade para dispositivos móveis
- Boa legibilidade
- Acesso rápido às programações
- Layout responsivo
